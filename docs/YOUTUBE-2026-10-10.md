# 2026-10-10 이재명 관련 유튜브 제목 2건 등록

조사 기간은 **2026-10-10 00:00~11:13 KST**다. 활성 등록 채널 27곳을 확인하고 성창경TV·스픽스·배승희 변호사·이봉규TV의 공식 채널 ID와 최근 업로드를 YouTube Data API로 재확인했다. 각 최근 50건에서 검토 명령이 출력한 이름·직함 후보 예시 **24건**을 읽었다. 그중 오늘 게시된 예시는 스픽스 1건·배승희 변호사 2건이었다. 기존 수집 항목으로 재현되며 오늘 제목에 「이재명」을 직접 적은 배승희 변호사 영상 **1개 채널·2건**을 선정했다. 전체 200건이나 전체 등록 채널의 오늘 영상을 모두 검토한 집계는 아니다.

확인 수준은 **내용 미확인 — 제목 관찰만**이다. 두 공식 영상 페이지 접근은 모두 `Cache miss`로 실패했다. 전사본·발언 구간·내용 요약·주장 검증은 확보하지 못했다. 제목의 질문·감정 표현을 실제 발언이나 사실로 재서술하지 않는다.

## 범위와 중복 처리

- 선정 URL은 최신 main의 기존 불변 원본에 없었다. 오늘 뉴스 [PR #59](https://github.com/EtainClub/ljm-wiki/pull/59)에 이미 등록한 장용진TV 영상 2건과도 다른 URL이다. 이번 조사 원본 2건을 별도 브랜치에 추가한다.
- 성창경TV·이봉규TV의 출력 예시 각 6건은 모두 이전 날짜여서 선정하지 않았다. 스픽스의 [오늘 10:17:52 다시보기 제목](https://www.youtube.com/watch?v=wGLFCltqA_0)은 공식 API에서 확인했지만 오늘 수집 원본 export에서 나오지 않았다. 최근 업로드 조회·수집 범위의 차이를 기록하고 이번 선정에서 보류했다. 스픽스·성창경TV·이봉규TV 전체의 오늘 영상이 없다는 뜻은 아니다.
- 공식 검토 명령의 넓은 후보 수는 성창경TV 17건·스픽스 6건·배승희 변호사 26건·이봉규TV 7건이다. 이는 이번 선정 수나 이재명 관련 독립 보도 수가 아니다. 출력된 예시 24건은 오늘 게시 3건·이전 날짜 21건이다.
- 수집은 언론과 유튜브를 합한 52개 source에서 성공 52·실패 0, 신규 154건·제목 변경 11건이었다. 이번 등록 수와 구분한다. 조하나의 아일랜드의 신선한 항목 0건을 미보도로 해석하지 않는다.
- 최근 48시간 수집, 채널당 최신 25건 수집·최대 50건 검토 조회, 최대 6건 후보 예시, 등록 밖 채널·삭제·비공개 영상, 관측 종료 이후 게시 영상은 조사 범위의 한계다.
