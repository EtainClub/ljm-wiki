- 성제준: 이번 최근 50개 제목 검토에서 관련 후보가 1건이어서 반복성 근거를 더 확보한 뒤 검토한다.
- 공병호TV: 이번 최근 50개 제목 검토에서 관련 후보가 없었다. 관련 방송을 하지 않는다는 판정은 아니다.
- 진성호방송: 확인한 ID의 업로드 목록이 2025년 7월에서 멈춰 있었다. 현재 운영 채널 확인 후 검토한다.
- 정규재TV: 공식 운영 채널 식별을 완료하지 못했다. 재업로드 채널을 대신 등록하지 않았다.

서울의소리의 독립운동가 이재명 의사 영상과 다른 대통령의 영상은 이름·키워드가 겹쳐도 선정 근거에서 제외했다. 장윤선 채널은 검색에 나온 `@SunniJang` 핸들이 API에서 조회되지 않아 고유 ID로 다시 확인했다.

## 재현 방법

- 등록 목록과 공개 근거: `src/data/youtube-channel-additions.json`
- 읽기 전용 검토: `npm --prefix functions run youtube:review -- <@핸들 또는 UC ID...>`
- 현재 등록 목록 확인: `npm --prefix functions run youtube:review`
- 검토 목록 적용: `npm --prefix functions run youtube:add-reviewed` (Firestore 쓰기, ID별 병합)
- 수집 확인: `npm --prefix functions run collect:once`

검토 명령의 `relatedCount`는 ‘대통령’ 등을 포함하는 넓은 제목 후보 수다. 동명이인·다른 대통령·같은 방송의 클립을 포함할 수 있으므로 이재명 관련 독립 보도 수로 해석하지 않는다. 등록만으로 모든 영상이 공개되는 것은 아니다. 기존 수집기가 최근 48시간의 후보를 저장하고, 사건별 검토·승인 후 공개 기록에 연결한다.
