# 유튜브 보도 관찰 확장

## 현재 구현

등록 채널의 승인된 사건 연결 영상을 `/youtube`에 모은다. 원제·게시 시각·제목 프레임,
제목 표기·변경 이력, 사건 맥락을 보여주며 채널·사건·검색어·제목 표현으로 탐색한다.
홈과 하단 탭에서 접근하고 사건 상세의 유튜브 목록은 기본으로 펼친다.
후보나 초안은 공개하지 않으며 기성 언론의 보도 여부 집계와 분리한다.

## 다음 구현 제안

1. **관찰 채널 선정**: 이재명을 반복적으로 다루는 논평·시사 채널을 등록한다.
   채널마다 선정 근거 영상 링크와 검토 날짜를 남긴다. 찬반 입장으로 배제하지 않으며
   일반 언론사의 유튜브 채널과 독립 시사 채널을 구분할 수 있다.
2. **영상별 검토 기록**: 논평·인터뷰·현장·토론·쇼츠 등 형식과,
   이재명에 대한 평가 발언·근거·타임스탬프를 편집자가 확인해 기록한다.
   하나의 영상 안에서 찬성·비판·혼합 평가가 공존할 수 있게 한다.
3. **내용 요약**: 제공받은 전사본 또는 검토자가 확인한 영상 구간을 근거로
   핵심 주장·제시 근거·이재명에 대한 평가를 짧게 작성한다.
   영상 원문과 구간 링크, 요약 작성·검토 날짜를 함께 저장한다.
   사건 요약·채널 설명·영상 내용 요약은 서로 다른 필드로 유지한다.
4. **도달 지표**: 조회·구독·댓글 수에 관측 시각을 붙여 보여준다.
   인기도를 기록하며 수치를 신뢰도나 실제 영향력 점수로 바꾸지 않는다.
5. **사건 비교 화면**: 같은 사건의 언론 제목과 유튜브 제목·검토 요약을 나란히 보여준다.
   최초 관측·후속 영상·제목 수정 기록을 타임라인으로 연결한다.
6. **놓친 영상 검토함**: 최근 전체 등록 채널 영상에서 인물 이름·관련 사건 핵심어로
   후보를 제안하고 편집자가 확인한다. 이름이 없는 긴 방송은 검토한 구간으로 연결한다.

내용 요약 단계에는 근거 자료와 검토 입력 경로가 필요하다. 채널·영상의 평가 분류는
제목만으로 자동 생성하지 않는다. 전체 채널의 정치적 성향을 고정 라벨로 붙이지 않는다.
