# 유튜브 채널 수집

유튜브는 기사와 같은 방식으로 취급하지 않는다. 이 프로젝트가 자동 수집하는 것은
**운영자가 명시적으로 등록한 채널의 제목·URL·게시 시각**뿐이다. 영상·오디오·자막을
다운로드하거나 스크래핑하지 않으며, 채널의 정당 지지·의도·신뢰도를 저장하지 않는다.

## 채널을 추가하는 법

채널 ID를 미리 찾을 필요가 없다. `@핸들`, `https://www.youtube.com/@핸들` 주소,
또는 `UC`로 시작하는 채널 ID를 입력하면 등록 명령이 YouTube API로 실제 채널과
업로드 재생목록을 확인한다. 이름이 비슷한 채널을 검색으로 골라 넣지는 않는다.

```bash
YOUTUBE_API_KEY=... npm --prefix functions run youtube:add -- "표시할 채널명" "@채널핸들" 100
```

예를 들어 `https://www.youtube.com/@parksiyoungTV`는 다음처럼 등록한다.

```bash
npm --prefix functions run youtube:add -- "박시영TV" "@parksiyoungTV" 100
```

명령이 출력하는 실제 YouTube 채널명과 채널 ID가 의도한 대상인지 확인한다. 이 명령은
한 번만 `channels.list`로 업로드 플레이리스트를 확인한다. 이후 수집기는 그
플레이리스트만 읽는다. 등록 뒤에는 다음을 설정하고 함수를 재배포한다.

```bash
firebase functions:secrets:set YOUTUBE_API_KEY
npm --prefix functions run deploy
```

`YOUTUBE_API_KEY`는 YouTube Data API용 키이며 AI 모델 API가 아니다.

## 화면과 분석의 한계

- 사건 프레임 안에서 `언론 기사`와 `유튜브 영상`을 별도 묶음으로 보인다.
- 유튜브 채널은 네이버 기사 검색의 대상이 아니므로 `보도하지 않음` 목록에 넣지
  않는다. 수집된 영상 제목이 사건과 직접 관련될 때만 해당 프레임에 표시한다.
- 프레임은 제목이 무엇을 앞세우는지만 서술한다. 예: `'의혹 제기'를 앞세움`.
- 영상의 발언, 자동 자막, 썸네일 문구, 제작 의도는 현재 분석 대상이 아니다.
- 따라서 특정 채널이 어떤 정치인을 지지하는 척한다거나 비방한다는 식의 라벨을
  붙이지 않는다. 그런 주장은 제목만으로 확인할 수 없다.

YouTube API의 자막 접근은 OAuth 권한을 요구하며, 제3자 영상의 자막·영상 수집과
교차 채널 API 데이터 집계에는 별도 정책 제한이 있다. 내용 기반 분석을 공개하려면
채널의 허가된 전사본 또는 별도 라이선스·약관 검토 경로를 먼저 마련해야 한다.
